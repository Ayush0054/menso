# Claude Code integration

`menso/` is an opt-in Claude Code plugin. It forwards session lifecycle, completion, notification, and permission events to the loopback listener owned by the signed Menso app. It does not edit `~/.claude/settings.json` or read Claude credentials.

## Contract

- The listener binds only to `127.0.0.1:49743` and accepts `POST /hook`.
- Every request must carry a random per-install `MENSO_HOOK_TOKEN` generated by Menso and stored in the user's Keychain.
- Lifecycle forwarding is best effort and has a two-second cap. Missing Menso or a rejected token is a no-op for Claude Code.
- `PermissionRequest` uses Claude Code's native HTTP hook transport and may remain open while the user acts. A connection failure or timeout falls back to Claude Code's own permission UI.
- Menso must answer with the current Claude `PermissionRequest` JSON contract. “Always” may echo only a suggestion that Claude supplied; Menso must not invent a broader rule.

Load this directory with Claude Code's normal plugin installation flow after Menso has placed the hook token in the environment it launches Claude Code with. The fixed loopback port is deliberate: Claude Code currently interpolates allowlisted environment variables in HTTP headers, not the hook URL.
