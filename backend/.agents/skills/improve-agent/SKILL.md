# Improve Menso

Use only explicit, redacted evidence references and the typed `LearningCandidate` artifact. Separate an approved runtime lesson from instruction/tool/schema/eval proposals. The Workflow may publish sanitized knowledge but cannot edit source. Source edits require normal Git review, and tool or policy changes require explicit maintainer judgment. Never learn raw third-party payloads or action authority. Do not run evals or deploy unless the user separately authorizes them.
